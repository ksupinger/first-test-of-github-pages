How it works

Intelligence in every compartment

Each ESP32 is a controller installed near the equipment it serves. After provisioning with the vessel’s mesh settings, compatible nodes discover one another and establish Wi-Fi links automatically. They can relay data over multiple hops and reconnect through available paths when radio conditions change.

Sense

Each node can sample analog and digital inputs such as tank levels, temperature, battery voltage, and switch states. Firmware can filter noisy signals, detect changes, and publish readings or alerts to the helm.

Relay

Nodes relay telemetry and commands between compartments. A helm display can show when data was last received and flag stale readings. Local rules can continue running when a node loses its link to the dashboard.

Act

A cabin node can read humidity and switch a fan through a suitably rated driver, then report the commanded state. The helm can send a manual override over the local mesh. Firmware can define how outputs behave at startup, after a restart, or when an override expires.

These Garmin examples show wired NMEA 2000 equipment. An ESP32 Wi-Fi mesh needs a compatible gateway to exchange data with an NMEA 2000 backbone.

Onboard uses

From the bilge to the helm

Place nodes close to the equipment they serve. Test radio links with hatches and doors closed, since metal bulkheads can weaken Wi-Fi signals.

Bilge
Report high-water switch state and pump run time.
Engine room
Track compartment temperature and battery voltage.
Cabin
Monitor humidity and control lights or fans.
